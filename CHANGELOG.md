## [1.0.0] - 2026-08-24

### Added

- Initial canonical community release.
- ODH-ASD project identity, namespace, provenance ID and runtime fingerprint.
- Multi-region AWS read-only discovery.
- Inventory of compute, network, data, integration and security services.
- CloudTrail, VPC Flow Logs, WAF, Network Firewall, Route 53 Resolver and Security Lake discovery.
- CloudWatch Logs volume baseline using `IncomingBytes` and `IncomingLogEvents`.
- Source-to-destination matrix for duplicate-ingestion analysis.
- Account-aware output packaging and evidence collection.
- ODIN // HELL / `0d1n-H3ll` canonical project identity.
- Architecture, security model, output-reference and compliance-alignment documentation.
- Community fork and contribution guidance.
