# AWS Stellar Cyber Discovery v1.0.0

First canonical community release by `0d1n-H3ll`.

## Highlights

- Read-only AWS discovery across enabled regions.
- Security-relevant asset inventory.
- Logging destination mapping for CloudTrail, VPC Flow Logs, DNS and Security Lake.
- 30-day CloudWatch Logs baseline by default.
- Average GB/day, peak GB/hour, event volume and peak hourly-average EPS indicators.
- Packaged evidence for follow-up sizing and onboarding decisions.
- Explicit project provenance and canonical-source metadata.
- Community fork and contribution workflow.

## Safety

The tool does not intentionally create, modify or delete AWS resources. Use a least-privilege read-only permission set and treat generated discovery packages as sensitive environment data.
