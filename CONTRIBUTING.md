# Contributing

Contributions are welcome through issues and pull requests.

Please keep the tool read-only by default, avoid customer-specific identifiers or credentials, and document any AWS API permission added to the discovery scope.

Changes that introduce write actions, resource mutation, credential collection, hidden collection or obfuscated behavior will not be accepted into the canonical project.

## Recommended flow

1. Fork `0d1n-H3ll/aws-stellar-discovery`.
2. Create a feature branch.
3. Keep changes focused and documented.
4. Run ShellCheck and validate the script in a non-production AWS account where possible.
5. Open a pull request against the canonical repository.
